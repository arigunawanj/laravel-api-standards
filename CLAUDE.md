# Project Standards

Project ini mengikuti **Laravel Ari Standards** (naming convention, struktur folder,
response macro, security, dsb).

Baca dan patuhi seluruh isi `AGENTS.md` di root project ini sebelum membuat atau
mengubah model, controller, migration, request, atau resource.

Skill lengkap (versi native Claude Code, dengan auto-trigger) juga tersedia di
`.claude/skills/laravel-ari-standards/SKILL.md`.
