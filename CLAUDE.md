# Project Standards

Project ini mengikuti **Laravel API Standards** (naming convention, struktur folder,
response macro, RBAC, security, dsb).

Baca dan patuhi seluruh isi `AGENTS.md` di root project ini sebelum membuat atau
mengubah model, controller, migration, request, resource, atau RBAC.

Sebelum meng-install package opsional (Reverb, AI SDK, Excel, PDF), tanyakan dulu
ke user mana yang dibutuhkan (lihat bagian "0. Protokol Agent" di AGENTS.md).

Versi skill dari standar ini juga tersedia di folder skills agent
(`.claude/skills/`, `.agents/skills/`, `.gemini/skills/`, `.agent/skills/`).
